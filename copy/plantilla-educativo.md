# Plantilla: carrusel educativo

De 6 a 8 slides, con **un máximo de 25 palabras por slide**.

| Slide | Función | Texto (≤ 25 palabras) |
|---|---|---|
| 1 | Portada: gancho fuerte | |
| 2 | Tip 1 | |
| 3 | Tip 2 | |
| 4 | Tip 3 | |
| 5 | Tip 4 | |
| 6 | (opcional) Tip 5 | |
| 7 | (opcional) Tip 6 | |
| Última | Cierre + CTA: guardá / compartí / escribinos | |

## Ideas de ganchos para la portada

- "3 errores que encarecen tu compra en Punta del Este"
- "Lo que nadie te dice antes de comprar en José Ignacio"
- "¿Alquilar o comprar en temporada? Hacé esta cuenta"

## CTAs de cierre

- "Guardalo para tu próxima visita a Punta 📌"
- "Compartilo con quien está pensando en invertir"
- "¿Tenés dudas? Escribinos por privado"

## Copy del posteo

```
[Gancho: retomá la portada en una línea]

[2–3 líneas de contexto o resumen de los tips]

[CTA: guardá / compartí / escribinos]

#PuntaDelEste #[hashtags del tema] #[hashtags locales]
```

## Diseño

- Usá la plantilla de Canva y el brand kit de Coldwell Banker Zetaté.
- **No inventes colores ni tipografías.**
- Exportá en 4:5 (1080x1350).
